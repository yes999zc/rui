## 智能体分工建议

- **UI 智能体**：`web/src/views/SetupView.vue` + `web/src/api.ts` + `i18n.ts`（向导）
- **音频智能体**：`audio/process.py` Pacer 预缓冲/可观测性 + `config/schema.py` 播放字段 + 测试
- **设备管理后端**：`web/api/app.py` devices 端点增强 + 测试（不改 UI）
- **设备管理前端**：`web/src/views/*`（等 UI 智能体交付后，避免 api.ts 冲突）
- **LX06 抽包**：等 P2.3 通过后，独立仓库/包 + 核心 loader 调整（大改，单独窗口）
