## 已知限制（不阻塞发布）

沿用 0.7.2 的运行时限制（未在 0.7.3 改变）：

1. **cue 回声的边界情形**：冷启动且不削波且设备滞后 >800 ms、或用户与 cue 重叠 <110 ms 时，cue 仍可能进入 ASR。
2. **`runner.abort()` 仍是全局单标志**：A 房唤醒会中止 B 房正在合成的回复（runner 单会话限制）。
3. **已播出的告别尾音无法追回**：只能阻止后续 chunk。
4. **唤醒词不按房间隔离**；`DOT2_CONTROL_PORT` 是全局 env。
5. **多设备并发未测**（音量/指示灯/四台同时在线）——见 HANDOFF「待设备」段。

> 0.7.2 的第 6 条（`uv.lock` 内仍写旧版本号 0.2.0）已在 0.7.3 修复：`uv.lock` 的 `rui` version = 0.7.3，`uv lock --check` exit 0。

## English（release notes 摘要 / for the GitHub release）

**rui 0.7.3 · rui-dot2-bridge 1.3.1 · rui-xiaoai-bridge 0.2.1** — three MIT-licensed repos.

**This release has no behaviour change.** 0.7.3 is test and CI infrastructure, a
coverage/gap ledger, and documentation consistency work; runtime paths and the
plugin contract are unchanged.

### What changed in rui 0.7.3

- **Coverage is produced by every CI test job** (Python 3.11 and 3.12) and uploaded
  as `coverage-<py>` artifacts. `scripts/coverage_report.py` generates the package
  table and the machine-readable baseline; 0.7.3 is **80.95% line / 69.55% branch**.
- **An independent `rui plug-test` smoke** runs against `tests/fixtures/sample-plug`,
  with no dependency on `plugs/xiaoai` (removed in 0.7.5).
- **Batch-1 unverified items became automated tests**: a null `first_response_ms`
  stays evidence-insufficient (never 0), the source-run `plugs/` fallback authorises
  an in-process adapter, and dot2 `stop_playback` on an active stream no longer
  swallows the next reply. Each test has a reverse mutation check.
- **Documentation**: a per-package coverage ledger with a three-way gap
  classification, 26 real-device protocols (command / criterion / record table),
  and eight resolved document contradictions across the three repos.

### Bridges

- `rui-dot2-bridge 1.3.1`: no code change, version unchanged; adds a D2-06 regression
  test only. `rui_compat` stays `>=0.6.0 <0.8.0`.
- `rui-xiaoai-bridge 0.2.1`: no code change, version unchanged.

### Evidence

- house-ear: **1651 collected / 1634 passed / 17 skipped / 0 xfail**; dot2 **145
  passed**; xiaoai **9 passed**; coverage **80.95% line / 69.55% branch**
  (`docs/audit/coverage-baseline.md`); `ruff` green in all three repos.
- CI: `ci` / `security` / `secret-scan` / `docker-publish` are green on tag `v0.7.3`
  (run links live in GitHub Actions and the release table in `docs/HANDOFF.md`).

### Known limitations

Unchanged from 0.7.2: cue-echo edge cases, single-session dialogue runner,
non-recallable spoken goodbye, per-room wake-word isolation, and untested
concurrent multi-device behaviour. The 0.7.2 `uv.lock` stale-version limitation is
fixed in 0.7.3.
