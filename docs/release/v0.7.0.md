## 真机重点（一次做完）

1. 播放中打断：音量 40 与 100 各 5 次，确认「音乐直接停、不再说在呢、紧接着的话一次识别对」。
2. 退下：说「退下吧」→ 等告别结束 → 再说「你好小瑞」连续 3 次，确认不需要重启（task-9）。
3. 空闲告别：「我先下啦」后确认会话关闭、仍可被「你好小瑞」唤醒。
4. 多设备：4 台同时在线，逐台添加/测试/删除，互不串台。
