# rui 0.8.10

**2026-10-29** · [完整 changelog](../../CHANGELOG.md) · 插件不变（dot2 1.3.5 / xiaoai 0.2.3），
`rui_compat` 不变（`>=0.8.1 <0.9.0`）· **本批已授权上线**：镜像 digest 由 tag 的
docker-publish 产出，实际 `up -d` 由 9哥 / bridge 确认后执行（本卡只交付版本与验证清单）。

0.8.10 的主题是「每一次唤醒、每一次打断都有回应」。这批 5 张卡（+1 张跟进）关掉的都是
**静默失败**：点歌失败被当成成功回答、噪声/空转写被直接丢弃、cue 被切除的沉默唤醒把房间
锁死 20 s、收藏不支持的来源被说成「服务器没响应」、HA 参数错误被说成「设备连不上」。
另外把采集削波从「玄学」变成可观测的指标。无协议破坏性变更，两个桥仓零改动。

## 改了什么

1. **T1 沉默唤醒不再锁死房间（+T1b）**：cue 被切除的唤醒不增 `idle_events`，控制面收不到
   `WakeIdle`，one-turn 闩一直开到 20 s watchdog，期间同房间每次唤醒都被
   `rejected: turn_open`。超时路径现在无条件上报 `WakeIdle`（watchdog 保留为兜底、降
   debug）；**T1b** 让已有 turn 在转写/播报时忽略迟到的 `WakeIdle`，不拆掉正在进行的回合。
2. **T2 点歌失败不再静默**：`local.music_play` 只对 `ok`/`ok_one` 保持 `silent`，失败
   （`not_found`/`unreachable`/`unresolved`）先判后播、念出短语；播放入口要求非空结果；
   artist-pool 兜底按标题接受度过滤，模糊池子不再播无关翻唱。
3. **T3 收藏三态**：`StarStatus(ok/unsupported/rejected)` 取代裸 bool；unsupported 说
   「这个来源不支持收藏」，bool-only 来源语义不变，未知返回值按 rejected 并记日志。
4. **T4 HA batch 参数归一（issue #34）**：`ha_batch_get_state` 接受单数 `entity_id`
   （字符串或列表）等所有形状并归一为 `entity_ids: list[str]`；参数/校验失败映射到
   `bad_args`，文案说「这次没查到」而不是「设备离线」。
5. **T5 barge/失败反馈 + 削波可观测**：barge 短提示（`audio.ack.barge_ack` 默认 `true`，
   80–160 ms，不开 gate hold/echo；`ack.mode: none` 或静音设备仍静默；`false` 回到旧
   行为）；噪声/空转写回「没听清，你再说一遍」且会话不关，barge 的 `WakeIdle`（新字段
   `WakeIdle.barge`）说同一句、普通沉默唤醒仍不说；`|x| ≥ 0.97` 连续 5 帧超 1% 记一次
   overdrive burst（限频 WARNING），Metrics 增 `overdrive_count`/`overdrive_ratio_max`/
   `last_overdrive_at`，`[seg]` 行削波 >5% 时带 `clipped=NN%`。

## 部署清单

**部署前提**：9哥 / bridge 确认窗口；`rui-xiaoai-bridge`、`rui-dot2-bridge` 不需要动。

1. 备份 `/config/config.yaml`、`/config/plugins/`、`rui-dot2-override.yml`（含当前镜像 digest）。
2. 在 `rui-dot2-override.yml` 的 `environment` 加一行 **`DOT2_MIC_GAIN_DB: "12"`**
   （治近讲削波；只改 override 环境变量，不改桥代码）。
3. `docker compose -f docker-compose.yml -f rui-dot2-override.yml pull`
4. `docker compose -f docker-compose.yml -f rui-dot2-override.yml up -d rui`
5. 按下面「部署后验证清单」逐项核对；任一红即回滚（见回滚锚）。

**生产运行时参数不动**（部署后核对）：capture 16 kHz / 8 ch / 6 mic + 2 ref /
`mic_shift=10` / `ref_shift=16`；keywords `:4.00 #0.07 @你好小宝`（客厅）与
`@你好小瑞`（dot2 三台）；`wake_preroll_ms=500`；`standby_kws_gate=false`；
AEC `cancel=mix filter_len=4096`。

## 回滚锚

- **0.8.9 = commit `a1d5afe`**（已发布、未部署）；**0.8.8 = commit `2dac336`**（当前生产）。
- 回滚只需回退 rui 镜像/版本；**回滚到 0.8.8 时建议把 override 的 `DOT2_MIC_GAIN_DB` 恢复为 18**
  （12 是本次为治近讲削波做的取舍，约 −6 dB 采集电平，会改变 0.8.8 的基线听感/ASR 电平）；
  两个桥仓始终不需要改。
- 部署前的 config/plugins/override 备份与镜像 digest 记录在 `docs/HANDOFF.md`。
