# RUI 0.8.19

## 中文

- 音乐选择、操作澄清和重说提示会给出短暂的接话窗口。窗口长度服从现有的设备和会话配置。
- 音频层按真实收音状态发出等待说话的灯光指示。支持该效果的 Dot2 桥使用绿灯。
- 提醒到点时在目标房间播报，播放中的音乐暂让扬声器，播完接着播放。手动暂停的音乐继续保持暂停。
- 修复 Trivy 限期例外的 YAML，发布流程先扫描 amd64 镜像，再更新镜像标签。
- 更新运行镜像内的 APT 和配套库，修复 CVE-2026-109518。

## English

- Music selection, command clarification, and repeat prompts open a bounded follow-up window subject to device and session settings.
- The audio plane drives the listening indicator from the receive window. The Dot2 bridge uses green for this state.
- Due reminders play in their target room. Music resumes after the reminder, and manually paused playback stays paused.
- Corrected the dated Trivy exception file and gated registry tag updates on an amd64 image scan.
- Updated APT and its shared library in the runtime image to fix CVE-2026-109518.
